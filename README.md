# 🎮 Python-Game-Project

> A collection of interactive terminal games and object-oriented Python modules featuring a fully interactive Tic-Tac-Toe game and an Enemy combat simulation.

## ✨ Project Modules

### 1. ⭕ Tic-Tac-Toe (`tictactoe.py`)
A command-line 2-player Tic-Tac-Toe game built using Object-Oriented Programming principles:
- **Interactive Board Grid:** Dynamic $3 \times 3$ matrix display in the terminal.
- **Game Logic:** Turn toggling (`X` and `O`), validation for occupied spots, dynamic horizontal/vertical/diagonal win checking, and draw detection.

### 2. 👾 Enemy Combat Simulation (`enemy.py`)
An OOP module demonstrating class structures and basic RPG mechanics:
- **Custom Attributes:** Enemy name and initial Hit Points (HP).
- **Interactive Actions:** War cries (`shout()`) and damage intake logic (`take_damage()`).

### 3. 🛠️ Practice & Utility Scripts
- **`bank.py`**: Account management / banking logic simulation.
- **`division.py`**: Safe division utility with zero-division checks.
- **`email.py`**: Basic string parsing or validation utilities.
